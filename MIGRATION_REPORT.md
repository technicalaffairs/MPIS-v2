## 3. The six transformer test procedures

The six test procedures in `appr_docs/ad_subst/ad_sub_tp/`:

| Doc | English source | Arabic version | Status in v2 |
|---|---|---|---|
| T-022-r0 — DC Winding Resistance Test (5 pp.) | PDF + `.htm` | `new_translated/T-022-r0a.htm` (already in v1) | Migrated as-is, paired |
| T-024-r0 — Three Winding Megger 5000 V (6 pp.) | PDF + `.htm` | `new_translated/T-024-r0a.htm` (already in v1) | Migrated as-is, paired |
| T-024-r0-ter — Two Winding + TER Megger 5000 V (5 pp.) | PDF only | **none anywhere in v1** | **New faithful Arabic translation created in v2** (`tools/translate_t024_ter.py`) |
| T-025-r0 — Tan δ Dissipation Factor (4 pp.) | PDF + `.htm` | `new_translated/T-025-r0a.htm` (already in v1) | Migrated as-is, paired |
| T-026-r0 — Two Winding Megger 5000 V (4 pp.) | PDF + `.htm` | `new_translated/T-026-r0a.htm` (already in v1) | Migrated as-is, paired |
| T-027-r0 — Turns Ratio Test (5 pp.) | PDF + `.htm` | `new_translated/T-027-r0a.htm` (already in v1) | Migrated as-is, paired |

Total: 29 pages, ~3,900 English words. The T-024-ter translation follows
the terminology of the existing T-024-r0a Arabic version (تشريط = short
circuit, بوشنج = bushing, ميجر = megger) and preserves the structure
exactly: Introduction, Safety Precautions, Work to be Carried Out
(Tests 1–5), and the record-sheet table with empty fields. Fields left
blank in the English original (Issued to / Status) stay blank.

**Correction to an earlier assumption:** these six were first described
as "English-only". That is true for the *PDFs in `arabic_web/`* (no
`T-022-r0a.pdf` etc. exist there), but five of them already had complete
Arabic **HTML** translations in `arabic_web/.../new_translated/`. Only
T-024-ter was missing an Arabic version entirely. The v2 translation for
it is the only new translation in this repository.

**Known discrepancy in the source (not fixed silently):** the PDFs
T-022, T-024, T-024-ter and T-026 contain Arabic appendix pages inside
the same PDF, and those embedded Arabic pages contain errors versus the
English text — e.g. in T-024 the Arabic Tests 6 and 7 are both labelled
"HV → LV1", while the English says Test 6 is HV → LV2 and Test 7 is
LV1 → LV2. The v2 site uses the English text as the source of truth and
the (correct) `new_translated/` Arabic pages; the embedded-PDF Arabic is
preserved verbatim in the PDF-derived JSON for audit, flagged
`pdf_has_embedded_arabic_pages: true`. A human reviewer should confirm
the T-024-ter translation and the T-024 Tests 6–7 labels before
operational use.

## 4. What was NOT migrated faithfully / needs human review

1. **Double-encoded Arabic (fixed, verify a sample).** The five
   `new_translated/` Arabic HTML files were saved with double-encoded
   Arabic in the original repo (UTF-8 bytes mis-decoded as Windows-1256
   and re-saved — e.g. `ظ…ط­ط·ط§طھ` instead of `محطات`). The migrator
   repairs this per-token (`repair_mojibake()` in `tools/migrate.py`)
   and the repaired text now reads correctly (verified: "الفازة R (أ)",
   "إجراء فني معتمد", "يحتوي هذا المستند على خطوات وإجراءات اختبار
   مقاومة الملفات…"). Spot-check a few of the 12 affected documents
   before trusting the repair blindly.
2. **15 documents have no extractable text** (image-only drawings/charts
   and blank forms). They are kept with metadata + source path, but their
   content is the image, not text. List: `about/Dev_Process/dev_chrt.htm`,
   `arabic_web/Ar_app_gen/EDEPC/Fire control/Ar_fs-050-r0.htm` (+ English
   twin), `arabic_web/Ar_draf_docs/Ar_draf_gen/A_draf_gen.htm`,
   `forms/QC_Forms/chem_Condenser.htm`, `gen_docs/app_gen/EDEPC/all_docs/
   Turbines/GT-002+03-dwgs.htm`, `GT-002+3-263/270/271/273/275/279/282/285/
   289.htm`. These need OCR or manual transcription if the text matters.
3. **1,199 image references unresolved** (of 4,740 references in the
   migrated HTML). 2,925 images were copied into `site/dist/assets/img/`.
   Unresolved references are mostly: images in `*_files/` folders from
   Word exports, wrong relative paths (`graphics/...` that does not exist
   next to the document), and files that do not exist in v1 at all
   (e.g. `images/mpis-2.gif`). Full list (first 50) in
   `site/dist/build_log.json`.
4. **Tables truncated at 200 rows** per table in extraction (flagged
   `truncated_rows` in the JSON). A few very large layout tables in the
   old FrontPage pages hit this; the original files are referenced by
   `source_path` for audit.
5. **Text truncated at 60,000 characters** per document (`text_truncated`
   flag). A small number of very long pages hit this; their `sections`
   are also capped at 600 blocks.
6. **Office binaries not converted** (`.doc` / `.xls` / `.ppt`, 88 files).
   Their content is not in `content/`. Converting them needs LibreOffice
   and is a separate step.
7. **Translation coverage is not complete.** 2,095 documents (46%) exist
   in one language only — mostly `protection` (230), `appr_docs` (362),
   `substations` (419) and `gen_docs` (316). They are shown in their
   original language with a visible "translation missing" notice. Only
   the six transformer tests above were translated in this pass; the rest
   needs a proper technical-translation pass, not machine translation
   without review.
8. **PDF text extraction is layout-based** (`pdftotext -layout`). Tables
   in PDFs become plain-text pages; column alignment is preserved
   approximately, not exactly. Scanned-image PDFs would yield no text —
   none of the 68 unique PDFs was in that state (0 PDF errors).
9. **The old chatbot is not ported.** v1 `chat_server.py` called Cohere
   with a hard-coded key (a security problem — the key is not in v2).
   `server.py` provides browsing + search; AI chat is optional and reads
   `COHERE_API_KEY` from the environment only.
